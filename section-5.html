SECTION 05

5. 數據列表與卡片展示模塊

對應來源：功能修改對照表 - 資料列；彩票欄位定義表

5.1 視圖模式切換

📌 預設視圖規格：系統進入與載入時，默認展示為 “列表模式”

本次改版將二維高密度的「列表模式 (Flat List View)」定為初始載入之默認視圖，核心定位為盡可能讓畫面一次展示多條數據之間的橫向比較，且點擊左側箭頭展開即可查閱更多資訊卡片；而「巢狀樹狀模式」則專注於盡可能展示單一用戶所有的相關完整資訊與代理階層。操作員切換後的偏好將自動由前端持久化記憶。

📋列表模式核心介面特徵與交互規範：
  • 1. 表頭固定吸頂 (Sticky Header) 與篩選列收起：列表表頭固定在頂部。當畫面向上滑動（頁面向下瀏覽數據）時，上方多欄位篩選表單會自動向上收起隱藏（連動 4.5 節規範），以最大化表格資料列的垂直檢視空間，操作員仍可持續對齊各欄位表頭。
  • 2. 列表展開按鈕與橫向滑動瀏覽：列表模式每列最前面均配有展開按鈕（> / v）。點擊展開後即可看到詳細卡片（包含「基本資料」、「存取款資料」、「成長與積分」、「推薦關係」等小卡），詳細卡片支援左右滑動瀏覽 (Horizontal Scrollable)，確保在有限寬度下完整容納所有維度資訊。
  • 3. 右上角自訂欄位功能與下方抽屜：列表右上角配置自訂欄位按鈕（圖示為 [ ▯▯ ]），點擊後由畫面底部滑出「自訂欄位設定」抽屜（抽屜高度嚴格限制不會超過表頭），可自訂顯示欄位與卡片是否呈現於一級主表或卡片內（詳見下方 5.3 節專題）。
  • 4. 金額表頭排序功能 (Amount Header Sorting)：所有金額與餘額相關之一級表頭（如可用額度、存款總額、取款總額、三方餘額等）均內建排序功能（參照圖三：存款总额 ▲ 📌）。排序圖標原本隱藏，鼠標移入表頭即出現降序指示圖示；點擊依「降序 (▼) → 升序 (▲) → 還原隱藏」順序依序切換，啟動時箭頭高亮顯示，並自動重置至第 1 頁發送查詢（詳見 5.2.1 節）。
  • 5. 欄位釘選固定在最前面 (Freeze/Pin Column to Front 📌)：每個表頭右側均配有釘選圖示按鈕（📌）。點擊後該欄位即時「固定在最前面」（凍結於表格左側，接續在展開列與勾選列後方，參照圖四：用户ID 📌 與 可用额度 📌），並在右邊界呈現立體垂直分隔線；當右側其餘欄位進行橫向水平滾動時，已固定欄位始終吸附在左側保持可視，再次點擊即可解鎖還原原位（詳見 5.2.1 節）。

5.2 一級欄位定義與特殊展示邏輯

📌 一級主表欄位通用功能規範
• 全欄位固定功能 📌 支援固定：每一個一級欄位均配有「固定功能 (Pin/Freeze)」。操作員可視審核習慣將特定欄位鎖定於表格左側，橫向水平捲動時該欄位始終保持凍結可視，防範寬表格檢視時脫焦。
• 金額排序功能 ▼ / ▲ 支援排序：所有與「金額相關」之一級欄位均配有「排序功能 (Sort)」（如：可用額度、三方餘額、主錢包存取款、USDT 存取款總額等）。排序圖標原本隱藏，鼠標移入表頭時即浮現降序圖示，點擊即可依「降序 (▼) → 升序 (▲) → 還原隱藏」依序切換，方便財務與風控人員快速篩選高資產或大額充提會員。

5.2.3 列表模式展開卡片規格

💡 視圖模式適用性說明

本章節之「展開卡片」規格專屬於列表模式（List Mode）。操作員在二維表格中點擊每列展開按鈕時向下展開此卡片；而巢狀模式（Nested Tree Mode）架構則照舊維持既有代理體系卡片樣式，僅整合「頭像與在線狀態」欄位顯示。

📋1. 模組概述

「展開卡片」是用於會員列表中的詳細資訊面板。當管理員點擊表格左側的展開按鈕（> / ▾）時，該行下方會向外展開一個結構化的卡片容器，完整呈現該會員的綜合維度數據與標籤管理，方便管理員在不跳轉頁面的情況下進行快速審核與資料檢視。

🧩2. 介面佈局與資料分區

展開卡片內部採用多欄式區塊（Grid / Flex 佈局）進行資訊封裝，主要劃分為以下資料模組（包含 6 大常規模組與 1 個默認隱藏的信貸卡片模組）：

👤2.1 基本資料
展示會員的核心身分與聯絡歸屬：
  • 頭像與暱稱：左側展示會員頭像與加密顯示的用戶暱稱（如 mi***01）。
  • 真實姓名：會員綁定的真實姓名（若未填寫則顯示 -）。
  • 生日：會員的出生年月日（如 1986-01-08）。
  • 帳號類型：如「普通帳號」。
  • 會員類型：如「代理會員」。
  • 等級：對應的 VIP 等級標示（如 VIP 1）。
  • 註冊模式：系統註冊管道或模式（如「一般登録」）。
  • 手機號：綁定狀態（如「已綁定」或「未綁定」）。
💳2.2 存取款資料
採用對比表格形式，分別呈現主錢包與匯總數據，並區分幣種單位：
  • 存款總額 / 存款次數：歷史累計充值金額與成功次數。
  • 取款總額 / 取款次數：歷史累計提領金額與成功次數。
  • 提款預扣金額：因稽核或流水未達標而暫時預扣的金額。
  • 后台加款總額：由客服或管理員手動後台補入的總金額。
  • 后台扣款總額：由後台手動扣除的總金額。
📈2.3 成長與積分
展示會員在平台的活躍度與成長體系數據：
  • 成長值：當前累積的活躍成長點數。
  • VIP成長值：推動 VIP 升級專用的成長累積值。
  • 會員積分：可用於商城或活動兌換的積分餘額。
🤝2.4 推薦關係
展示下線與推廣分潤關係：
  • 幣種單位：明確標示當前計算的幣種（如 單位: RMB 或 VND）。
  • 邀請人 / 邀請碼：上級推薦人的帳號與綁定代碼。
  • 下級/團隊：直屬下線與團隊總人數統計（如 0/0）。
  • 佣金余额：透過推薦返利累積可提領的佣金金額。
💰2.5 餘額寶
展示理財或增值帳戶相關數據：
  • 幣種單位：對應的結算貨幣。
  • 餘額：存入理財帳戶中的本金總額。
  • 利息：已產生或累計派發的收益利息。
🏷️2.6 用戶標籤與備註
提供維運標記與聯絡備忘：
  • 用戶標籤：動態展示多個維運標籤（如 VIP 客戶、高頻交易、大戶、新註冊 等）。
  • 備註：管理員手動填寫的長期備註（支援長文本截斷與檢視）。
  • 回访备注：客服或電銷團隊的回訪紀錄備忘。
💳2.7 信貸
⚠️ 默認隱藏
展示會員授信借貸與信用評級數據。考量敏感風控資產安全，本卡片及內部字段系統預設隱藏，需具權限者於自訂抽屜主動勾選開啟：
  • 借貸金額 (欠款)：默認不顯示 會員目前累計借貸尚未還款之本金總額（欠款數值，如 50,000.00），支援借款流水追溯。
  • 信用值：默認不顯示 會員在平台內部評定之信用評分或信貸額度指標（如信用分數 85 分或信用評級）。
⚡3. 互動行為與需求
• 收合與展開控制：
點擊表格最左側的展開列圖示（> / ▾），觸發向下展開動畫；再次點擊則收合卡片。系統支援「單行展開」或「多行同時展開」，預設允許多個會員卡片同時展開以方便跨用戶比對數據。
• 數據快捷連結：
卡片中的金額數字（如存款總額、佣金餘額等）若帶有底線或互動樣式，點擊後應可直接導向對應的明細報表或流水紀錄頁面，縮短操作路徑。
• 文本溢出處理：
針對「備註」等可能出現極長字串的欄位，介面需支援自動斷行、CSS 省略號（Ellipsis）顯示，或滑鼠懸停（Hover）時透過 Tooltip 浮層顯示完整文字內容，避免版面變形。

5.3.4 特殊欄位合併與彈層展示邏輯

特殊欄位設計 整合呈現規則

3.1 欄位膠囊控制項與微調排序
(圖 A 示範)
:: 👁 / 👁‍🗨 < / > ✕
互動邏輯與功能說明：
• 拖曳排序 (Drag & Drop)：按住最左側六點手柄（::）可在同一群組容器內自由拖動，即時產生佔位預覽推擠效果。
• 步進微調排序 (Step Left / Right)：膠囊內配備 <（向左移動一位）與 >（向右移動一位）微調按鈕。針對不便進行滑鼠長距離拖曳的操作員，提供精準步進位移；邊界防呆機制：當欄位處於首位時 < 自動置灰禁用（如圖 A 中 存款总额），處於末位時 > 自動置灰禁用。
• 可視切換 (Visibility)：點擊眼睛 👁 即刻切換為隱藏 👁‍🗨，主表或卡片同步隱藏。
• 快速移除 (Remove)：點擊淡紅色背景之 ✕ 按鈕，即刻將該欄位自當前配置區域中移除，並歸還至待選欄位庫。
• 常態與懸停反饋：未懸停時維持簡潔膠囊樣式（如圖 A 右側 👁 取款总额）；滑鼠懸停 (Hover) 時平滑展開位移微調與移除按鈕組。
3.2 待選欄位快捷新增
(圖 B 示範)
+
互動邏輯與功能說明：
• 常規待選池欄位：庫中尚未配置之常態可用欄位（如圖 B 用户标签）右側配備 + 按鈕。
• 一鍵快捷加入：點擊 + 按鈕後，系統自動將該欄位加入至目標展示區塊（主表或卡片內部末位），該按鈕即時變更為已加入狀態或轉入已啟用容器中。
3.3 預設隱藏敏感欄位啟用
(圖 C 示範)
👁‍🗨 +
互動邏輯與功能說明：
• 預設隱藏保護：信貸卡片等敏感欄位（如圖 C 欠款、信用值）預設維持不顯示狀態，圖示以斜線眼睛（👁‍🗨）明確標示。
• 手動授權啟用：具備相關管理權限之操作員點擊 + 按鈕後，系統將該敏感欄位加入卡片，且圖示立即點亮切換為正常顯示狀態 👁；若後續點擊 👁 或 ✕ 移除，則重新還原為 👁‍🗨 預設隱藏狀態。
3.4 模組卡片與次分組階層收合管理
(圖 D 示範)
:: 🔒 ^ / v
互動邏輯與功能說明：
• 模組整組拖曳：卡片最左側配有六點手柄（如圖 D :: 存取款资料 🔒），操作員可按住手柄上下拖動，調整各模組卡片在列表展開時的先後展示順序。
• 核心分類鎖定保護：關鍵核心業務模組標註 🔒 鎖定圖示，不可整組隨意刪除或關閉，保障基本帳戶數據結構健全。
• 階層次分組結構：卡片內部支援次分組架構（如存取款資料內分設「主錢包」與「彙總 (USDT)」兩大子分組），各自收納所屬子欄位膠囊，資訊層次清晰。
• 獨立收合與展開：大卡片頂部與各次分組右側均配置 ^（收起）與 v（展開）按鈕。操作員可快速摺疊暫不調整的分組，極大縮短垂直滾動長度，提升高密度介面配置效率。
