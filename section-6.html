6. 單筆會員操作與詳情抽屜

對應來源：功能修改對照表 - 操作功能列；權限對照表

6.1 編輯用戶抽屜

管理員點擊資料列末端的行操作「編輯」按鈕時，系統自畫面右側向左平滑滑出 680px 一級抽屜容器。抽屜內提供會員個人帳號設定與營運參數調整，分設兩大核心頁籤，避免傳統多層覆蓋彈窗造成的視覺干擾。

圖一 編輯用戶抽屜介面示意圖 (修改用戶詳情 · 680px)
↗開新分頁檢視原圖
截圖特徵解析： 畫面右側向左滑出 680px 寬度的「修改用戶詳情」抽屜，頂部配有 [取消] 與 [保存修改] 主按鈕、會員身分標籤與狀態燈號；內部提供 基本信息 與 会员设置 雙頁籤，下方表單依業務分類為「賬戶概況」與「聯絡方式」。

📐6.1 編輯用戶抽屜介面佈局與元件詳細說明

1. 頂部標頭與操作控制列
• 標題與身分標識：動態呈現 修改用户详情 · {會員帳號}（如 mingv0717001），並隨附身分標籤（如 代理会员、VIP会员）。
• 即時狀態指示：以狀態點呈現當前運作狀態（以顏色區分：正常 / 凍結 / 停用）。
• 右側操作按鈕：
  • [取消]：放棄本次編輯輸入，平滑關閉抽屜還原原樣。
  • [保存修改]：主操作按鈕（以顏色區分主次操作），觸發資料校驗並提交後端 API，成功後即時刷新主列表並關閉抽屜。
2. 雙核心頁籤切換 (Tabs)
• 基本信息 (Default Tab)：涵蓋帳號核心識別身分、狀態切換與多渠道通訊方式。
• 会员设置：涵蓋金流通道指定（支付層級）、標籤多選綁定、提款黑名單限制開關、賠率與返點單獨微調（連動返點權限）。
3. 「基本信息」分區欄位規格詳解
分區名稱 欄位名稱 元件型態 業務規範與互動邏輯
賬戶概況
帳號、狀態、會員類型、等級		 账号 唯讀文字框 會員系統主鍵代號，不可手動修改，維持資料一致性。
会员类型 唯讀文字框 展示該會員身分屬性（如代理會員、直屬會員）。
账户状态 三段分段按鈕 (Segmented) 提供 [ 正常 ]、[ 冻结 ]、[ 停用 ] 快捷點選切換，選中項以顏色區分。
用户昵称 單行輸入框 支援管理員手動微調暱稱，同步更新前台展示。
真实姓名 單行輸入框 實名認證姓名；無資料時填寫顯示 -。需具備『修改真實姓名』權限方可解鎖編輯。
出生年月日 日曆選擇器 (DatePicker) 格式為 YYYY/MM/DD，支援手動輸入或點擊日曆圖示選取會員出生日期。
用户等级 下拉選擇器 支援指定特定 VIP 會員等級（如 VIP會員、一般會員）。
支付层级 下拉選擇器 指派該會員所屬之存提款金流層級（如預設層、大額VIP通道層）。
聯絡方式
敏感通訊渠道		 电话 輸入框 + [校验] 按鈕 輸入手機號碼，右側附帶 [校验] 按鈕供排查號碼格式與是否重複綁定。
email 單行輸入框 輸入電子郵箱，支援標準 Email 正則格式校驗。
QQ 單行輸入框 會員綁定之 QQ 號碼維護。
微信 單行輸入框 會員綁定之微信號（WeChat ID）維護。
Zalo 單行輸入框 東南亞市場專用通訊帳號維護。
WhatsApp 單行輸入框 國際通訊電話號碼維護。

6.2 會員詳情抽屜

點擊行操作「詳情」時自右側滑出 680px 完整會員檔案抽屜。詳情抽屜整合會員全生命週期數據，採用卡片式封裝，分為 4 個專業 Tab 頁籤，供管理員快速查核與風控審計。

圖二 會員詳情抽屜介面示意圖 (查看詳情 · 680px)
↗開新分頁檢視原圖
截圖特徵解析： 畫面右側滑出 680px「查看詳情」抽屜，頂部配有快速關閉 ✕ 圖示、身分標籤與狀態指示；分設 会员信息、会员审核、提现信息、设备与IP纪录 四大頁籤；內容區採卡片呈現「基本資料」與完整 8 大維度「聯絡方式」，無資料處統一規範顯示 "-"（以顏色區分弱化）。

📋6.2 會員詳情抽屜四大頁籤與卡片展示說明

👤 1. 會員信息
預設頁籤。頭像、身分識別、出生年月日、完整 8 大聯絡通訊矩陣、備註紀錄。
📝 2. 會員審核
連動『会员信息审核』權限。集中審核會員申請之姓名修改、手機解綁、歷史審核日誌。
💳 3. 提現信息
綁定銀行卡清單（增/刪/改/禁用）、USDT提現地址、累計提款次數與限額。
🌐 4. 設備與IP紀錄
註冊/登入 IP 地理位置、UserAgent、同 IP 關聯帳號數、同設備關聯帳號數（支援穿透至二級抽屜）。
基本資料卡片 (Basic Info Card)
• 頭像展示：左側展示圓形會員頭像（未上傳時呈現預設人物頭像輪廓）。
• 雙列資訊膠囊：右側採用資訊卡片，成對呈現「用戶暱稱 / 帳號」、「真實姓名 / 出生年月日」。
• 空值展示規範：真實姓名若未綁定，一律顯性顯示 "-"（以顏色區分弱化），嚴禁空白留白。
聯絡方式卡片 (Contact Methods - 8 大維度矩陣)
• 涵蓋管道：雙欄網格依序陳列 电话、Email、QQ、微信 (WeChat)、Zalo、WhatsApp、Telegram、Facebook。
• 統一安全脫敏與空值表現：未填寫或無綁定數據之管道，欄位框內部統一展示 "-"（以顏色區分弱化），杜絕舊版粗暴留白問題；具備資料者依後台敏感資訊查看權限進行加密脫敏或明文呈現。
備註與營運紀錄 (Remarks)
• 展示該會員歷次電銷跟進、風控加註、客服諮詢等歷史備註文字，支援超過長度截斷與展開完整歷程。

6.3 二級抽屜互動機制

為了解決多帳號刷水、同設備多開或同 IP 關聯群組的風控排查痛點，系統創新設計「一級抽屜 (680px) + 二級抽屜 (560px)」雙層抽屜穿透互動架構。操作員在審查特定會員時，無須關閉當前抽屜或跳轉新頁籤，即可快速深挖關聯風控大數據。

示意圖 二級抽屜互動機制介面示意圖 (一級詳情 680px + 二級關聯穿透 560px)
↗開新分頁檢視原圖
截圖特徵解析： 中間為 680px「查看詳情」一級抽屜，處於 设备与IP纪录 頁籤，卡片內列出最新登入/註冊之 IP 與設備號，並標註可點擊的「同IP人數」與「同設備人數」（以顏色區分連結樣式）；點擊後自一級抽屜右側滑出 560px「詳細內容」二級抽屜，表格逐筆列出關聯登入用戶、最後登入時間、IP 與地理定位資訊。
🔍
同 IP / 同設備穿透分析交互：
在詳情抽屜的「設備與IP紀錄」頁籤中，點擊 同IP人數: 60人 或 同設備數: 28台 標籤時，自一級抽屜右側滑出 560px 二級關聯抽屜，即刻展開該組 IP/設備所關聯之其他會員名單、登入時間與 IP 地理分佈，無須跳轉離開當前會員詳情。

⚡6.3 二級抽屜架構與互動詳細規範

1. 穿透觸發入口與數據分區
• 觸發位置：位於一級詳情抽屜的「設備與IP紀錄」頁籤。
• 數據卡片結構：分為「最新登入紀錄」與「註冊紀錄」兩張獨立卡片，各自包含：
  • IP 地址：展示 IP 字串（如 54.150.111.152）、地理歸屬（如 Japan, Tokyo），並配有一鍵複製按鈕與關聯圖示。
  • 設備號：展示設備唯一指紋代碼（UUID/Hash），配有外部跳轉/關聯圖示。
  • 同IP人數 / 同設備人數：以數字連結形式呈現（如 60、28、18，以顏色區分連結樣式）。滑鼠懸停顯示點擊提示，點擊立即喚出二級抽屜。
2. 二級抽屜介面佈局與表格規格 (560px)
• 寬度與外觀：二級抽屜固定寬度為 560px，頂部標題列（標題：詳細內容，以顏色區分抽屜層級），右上角配置向右收起箭頭圖示（→）。
• 關聯列表數據欄位：
列表欄位 資料屬性 功能互動與業務說明
登录用户 會員帳號 列出共享該 IP 或設備的所有會員帳號（如 test_user_5、test_user_5_1 ...）。
最后登录时间 日期時間 ⇅ 格式為 YYYY-MM-DD HH:mm:ss，表頭支援點擊依時間升序/降序排列。
IP 網路位址 顯示該用戶實際登入之 IP，右側配有一鍵複製圖示。
IP信息 地理定位 顯示國家與城市地理位置（如 📍 Japan, Tokyo），快速定位跨區登入風險。
3. 層級堆疊與關閉控制邏輯
• 獨立收起二級抽屜：點擊二級抽屜右上角 → 箭頭圖示或鍵盤按 Esc，僅向右滑出關閉二級抽屜，一級詳情抽屜保持原有位置與頁籤狀態不變。
• 全局快速關閉：點擊一級抽屜右上角 ✕ 或點擊左側底層遮罩區域，系統同時關閉一級與二級抽屜，一秒還原主資料列表。

跳轉/彈層帶入該用戶ID進行充提與投注對帳

連動權限，手動清除流水稽核或踢除在線 Token
